# 📂 CSS Folder Hover Animation

A clean and modern folder hover animation built with pure HTML and CSS.

Perfect for dashboards, file managers, portfolio websites, landing pages, and modern web interfaces.

---

## ✨ Features

* 📁 Smooth folder opening animation
* 🎨 Pure HTML & CSS (No JavaScript)
* ⚡ Lightweight & easy to customize
* 📱 Responsive design
* 🧩 Beginner-friendly code structure
